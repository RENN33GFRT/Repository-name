# README для модуля с функциями

## Описание

Данный модуль содержит две функции: `mask_account_card` и `get_date`, которые предназначены для обработки информации о банковских картах и счетах, а также для форматирования даты из строки в определённом формате.
 
## Функции

### `mask_account_card(card_inf: str) -> str`

Эта функция обрабатывает информацию о банковских картах и счетах, замаскировывая номера карт или счетов. 

#### Параметры:
- `card_inf` (str): Строка, содержащая информацию о карте или счете, например, "Maestro 1596837868705199" или "Счет 73654108430135874305".

#### Возвращаемое значение:
(str): Строка с замаскированным номером карты или счета.

#### Примечание:
Для маскирования карт используются функции `masks.get_mask_card_number()`, а для счетов - `masks.get_mask_account()`. Убедитесь, что эти функции определены и доступны.

### `get_date(date: str) -> str`

Эта функция принимает строку с датой в определенном формате и возвращает её в виде строки с более привычным форматом дня, месяца и года.

#### Параметры:
- `date` (str): Строка с датой в формате ISO, например, "2024-03-11T02:26:18.671407".

#### Возвращаемое значение:
(str): Строка с датой в формате "ДД.ММ.ГГГГ".
